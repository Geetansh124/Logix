# User Stories

## Expedition Planner

- **US-EP-001:** As an expedition planner, I want to create an expedition with dates, stations, and an assigned team so that all mission planning is centrally managed.
- **US-EP-002:** As an expedition planner, I want to generate a resource allocation plan by station and season so that required fuel, food, and equipment are available.
- **US-EP-003:** As an expedition planner, I want an optimized cargo manifest and stowage plan so that priority cargo is unloaded in the correct order.

## Cargo Handler

- **US-CT-001:** As a cargo handler, I want to scan a container QR code at each hub so that the system records custody and location automatically.
- **US-CT-002:** As a cargo handler, I want to record cargo condition on receipt so that damage, loss, and discrepancies are immediately visible.
- **US-CT-003:** As a cargo handler, I want to see my assigned containers and pending tasks offline so that I can work during connectivity loss.

## Station Manager

- **US-IM-001:** As a station manager, I want to update stock in or stock out offline so that inventory records remain accurate during communication blackouts.
- **US-IM-002:** As a station manager, I want stockout and expiry alerts so that I can take corrective action before essential supplies become critical.
- **US-PM-001:** As a station manager, I want to conduct daily roll calls so that personnel accountability is always current.
- **US-ER-001:** As a station manager, I want a one-click emergency alert so that NCPOR and MoES receive the incident details quickly.

## Emergency Responder

- **US-ER-002:** As an emergency responder, I want an emergency dashboard with a personnel snapshot and critical-resource status so that I can coordinate a response using current information.
- **US-ER-003:** As an emergency responder, I want to acknowledge, escalate, and resolve alerts so that the incident lifecycle is auditable.

## Asset Manager

- **US-AM-001:** As an asset manager, I want to register movable and immovable assets with a unique ID and lifecycle state so that ownership, location, and maintenance are traceable.
- **US-AM-002:** As an asset manager, I want maintenance schedules and overdue alerts so that mission-critical equipment remains serviceable.
